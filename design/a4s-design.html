你 提问 贝叶斯公式和全概率公式到底是什么关系？
A4S 基于 3 个片段作答

一句话：全概率负责把结果拆开算，贝叶斯负责把因果倒过来推。全概率是贝叶斯的分母，贝叶斯只是在这个分母上换了个分子。

讲义里先定义条件概率 P(A|B) = P(AB)/P(B)，再用互斥完备事件组把 P(A) 拆成求和，这就是全概率公式。贝叶斯把分子再用一次条件概率展开成 P(A|B)P(B)，于是得到"已知结果 A，反推原因"的式子。

设 B₁, B₂, …, Bₙ 为样本空间的一个划分，且 P(Bᵢ) > 0。若 P(A) > 0，则对任意 i 有 P(Bᵢ|A) = P(A|Bᵢ)P(Bᵢ) / Σ P(A|Bⱼ)P(Bⱼ)，其中分母即全概率公式展开的结果。 概率论 第7讲· p.18 · 片段 #0412

所以记忆上这样绑：分母永远是"总的原因"，不分先后；分子只挑你想问的那一条原因。分母一旦算好，所有后验概率共用它——这也是考试里常让你一次算完所有 P(Bᵢ|A) 的原因。

第 3 / 8 题 单选 概率论 第7讲 2 已答 · 1 正确

设 P(B) = 0.5，P(A|B) = 0.4，P(A|B̄) = 0.2，则 P(B|A) 等于：

A 0.20
B 0.667 正确答案
C 0.400 你的选择
D 0.800
解析回到原文

先算分母：P(A) = P(A|B)P(B) + P(A|B̄)P(B̄) = 0.4×0.5 + 0.2×0.5 = 0.3。再代贝叶斯：P(B|A) = 0.4×0.5 / 0.3 ≈ 0.667。

你的答案 0.400 恰好是分子 P(AB)，漏掉了除以分母这一步——这是本章最常见的失分点。

P(B|A) = P(A|B)P(B) / [P(A|B)P(B) + P(A|B̄)P(B̄)]，分母必须先由全概率公式展开，不能直接用 P(A|B)。 概率论 第7讲· p.18 · 片段 #0412
